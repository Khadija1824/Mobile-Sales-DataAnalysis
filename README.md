# 📱 Mobile Phone Sales Dashboard

An interactive web application built with **Streamlit**, **Pandas**, and **Seaborn** to explore, analyze, and visualize key insights from a comprehensive mobile phone sales dataset.

---

## 🚀 Features

* **Overview & Summary Metrics:** Quick high-level statistics including total records, unique brands, unique models, and a full statistical breakdown of numerical features.
* **Brand Analysis:** Visualizations showing brand distribution, market presence, and model counts per manufacturer.
* **Pricing & Discounts:** Detailed charts comparing average selling prices and discount percentages across different brands.
* **Raw Data Explorer:** An interactive data grid with dynamic brand filtering to drill down into specific records.

  🛠️ Prerequisites & Installation
Make sure you have Python 3.7+ installed on your system.

Clone or download this repository to your local machine.

Install the required Python libraries using pip:

pip install streamlit pandas matplotlib seaborn
🏃‍♂️ How to Run the App
Open your terminal or command prompt and navigate to the project directory containing app.py and Sales.csv.

Run the Streamlit application with the following command:

streamlit run app.py

📊 Dataset Information
The application utilizes Sales.csv, which contains various attributes of mobile phones including:

Brands & Models: Manufacturer and specific device names.

Hardware Specs: Colors, Memory, Storage, and Camera specifications.

Pricing & Offers: Original Price, Selling Price, Discount amount, and Discount Percentage.

Ratings: Customer feedback ratings.
